## Per-build process (same every time)
1. **Deep research** → verified data (no hallucination) — use graph double-check worker. Collect: services, reviews, owner, colors, logo, pricing, proof points, tagline.
2. **Assets** → logo (real or industry-themed generated), trade-specific hero still, 6-sec Grok hero video (brightened in-hero), HD service card images.
3. **Build** → Claude Code Builder from landscaper template (or last upgraded demo).
4. **Critic loop** → 8.5/10 visual bar, max 5 rounds, graph loop (fresh-context critic + verifier).
5. **Vision-verify** → Camoufox 1280 + 390 + Gemini, both viewports.
6. **Deploy** → deploy.py, PROJECT=<slug>-demo.
7. **SHOW ZACH** (first build only) → on approval, build + pitch rest autonomously.
