# Design Direction — Local Launch OS (flagship redesign)

Source: Astra (GPT-6) design-director pass, 2026-09-09. Owner brief: high-end,
elegant, HD; art everywhere; prospects as elegant names, NOT cheap cards.

## Core thesis
Change the *grammar*, not the packaging. A particle hero + nav cards is still a
generic dark dashboard. Sell the capability through exceptional work, then make
the next action obvious. "HD" = image quality + art direction, not more effects.

## Typography
- Headline/UI: a clean neo-grotesque (Neue Montreal direction → Space Grotesk as
  free stand-in), headlines 88–112px desktop / 48–56px mobile, weight 500,
  tracking −0.045em, line-height 0.98.
- Editorial accent: Instrument Serif italic, used for a single phrase.
- UI/body: 14–16px, weight 450–500. Avoid tiny widely-tracked uppercase everywhere.

## Layout — a sequence, not a grid
Three unequal chapters:
1. "Move work forward" → Approvals (pending decisions).
2. "Build the next client" → Pipeline + stage-ordered prospects index.
3. "See what we can make" → Demos (real site previews).
Reports = a quiet utility link. Persistent nav keeps every destination reachable.
- 80px desktop gutters, 1440px content max, 120–160px between chapters.
- Hero ≈ 65vh (not a full-screen obstacle).

## Imagery
- Particle art off-center, flowing toward the CTA; localized black→transparent
  text scrim (not uniform dimming); fade bottom edge into canvas; subtle grain.
- Remove the competing node background on content surfaces.
- Feature large crisp demo website previews (different industries) — real output
  owns credibility; abstract art only sets atmosphere.

## Furniture
Strip panel backgrounds, pill badges, shadows, glowing borders. Use hairline
rules, strong alignment, occasional full-width imagery. Reserve cyan/teal for
actionable or selected states only.

## Motion
180ms hover transitions; one restrained 500ms hero entrance. No perpetual
particles/scroll hijacking. Respect prefers-reduced-motion; never delay work.

## Prospects — an index, not cards
Group by explicitly numbered stage. Names 26–32px, quiet location meta,
right-aligned next action. Generous row padding, thin separators, visible focus,
understated hover underline.

## Fonts (concrete)
- Space Grotesk (Google) — display/headline.
- Instrument Serif (Google) — editorial italic accent.
- Geist (existing) — UI/body.
